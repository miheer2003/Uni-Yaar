# Plan 08-02: Frontend Facility Status & Issue Reporting UI

## Goal
Build an intuitive campus facility status dashboard and student issue reporting portal with active maintenance alerts, alternative recommendations, issue submission form, upvote counters, and status progression steppers.

## Key Changes
1. **Types & API Client**:
   - `frontend/src/types/facility.ts`: `MaintenanceNotice`, `IssueReport`, `FacilityStatus`, `IssueCategory`, `IssueStatus`, `IssuePriority`.
   - `frontend/src/api/client.ts`: `facilityApi` (`getMaintenanceNotices`, `getReports`, `submitReport`, `upvoteReport`).
2. **Components & Page**:
   - `frontend/src/pages/Facilities.tsx`:
     - Alert banner for active maintenance issues with alternative route guidance and "Locate on Map" CTA.
     - Tabbed views: "Campus Status & Maintenance" and "Community Issue Tracker".
     - "Report a Problem" modal dialog with category picker, building/floor selection, priority chips, and photo/notes input.
     - Upvote action ("Facing this too" +1 counter) to escalate high-impact campus issues.
     - Live issue status stepper badge (Reported -> In Review -> In Progress -> Resolved).
3. **Routing**:
   - Connect `/facilities` route in `App.tsx`.
