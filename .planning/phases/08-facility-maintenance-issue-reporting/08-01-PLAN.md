# Plan 08-01: Backend Facility Maintenance & Issue Reporting Engine

## Goal
Implement backend models, repositories, business services, DTOs, and REST endpoints for campus maintenance notices (with alternative facility suggestions) and student community issue reporting (with category, priority, status lifecycle, and upvote tracking).

## Key Components
1. **Entities**:
   - `FacilityStatus`: Enum (`OPERATIONAL`, `UNDER_MAINTENANCE`, `TEMPORARILY_CLOSED`, `RESTRICTED_ACCESS`).
   - `MaintenanceNotice`: id, title, description, status, affectedAsset, building, floor, room, alternativeSuggestion, estimatedResolutionTime, isActive, createdAt.
   - `IssueCategory`: Enum (`PLUMBING`, `ELECTRICAL`, `ELEVATOR`, `HVAC_AC`, `CLEANING`, `NETWORK_WIFI`, `FURNITURE`, `AV_PROJECTOR`, `OTHER`).
   - `IssueStatus`: Enum (`REPORTED`, `IN_REVIEW`, `IN_PROGRESS`, `RESOLVED`, `DISMISSED`).
   - `IssuePriority`: Enum (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
   - `IssueReport`: id, title, description, category, priority, status, building, floor, room, specificLocation, reportedBy (nullable User), upvoteCount, staffNotes, createdAt, resolvedAt.
2. **DTOs**:
   - `MaintenanceNoticeResponse`, `IssueReportRequest`, `IssueReportResponse`, `IssueStatusUpdateRequest`.
3. **Services & Repositories**:
   - `MaintenanceNoticeRepository`, `IssueReportRepository`.
   - `FacilityService`: listActiveMaintenance, createNotice, reportIssue, listIssues, upvoteIssue, updateIssueStatus.
4. **Controllers**:
   - `FacilityController`:
     - `GET /api/facilities/maintenance`
     - `GET /api/facilities/reports`
     - `POST /api/facilities/reports`
     - `POST /api/facilities/reports/{id}/upvote`
     - `PATCH /api/facilities/reports/{id}/status`
5. **SecurityConfig**:
   - Allow public read and report submission endpoints.
