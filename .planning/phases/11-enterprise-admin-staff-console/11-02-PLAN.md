# Plan 11-02: Frontend Enterprise Role-Based Admin & Staff Console

## Goal
Build a command center for University Staff and Administrators featuring operational KPI metrics, quick issue resolution queues, event publishing dialogs, emergency notice broadcasting, and user role controls.

## Key Changes
1. **Types & API Client**:
   - `frontend/src/types/admin.ts`: `AdminDashboardMetrics`, `AdminUser`.
   - `frontend/src/api/client.ts`: `adminApi.getStats`, `adminApi.getUsers`, `adminApi.updateRole`, `adminApi.createEvent`, `adminApi.createNotice`, `adminApi.createAnnouncement`.
2. **Page Component**:
   - `frontend/src/pages/AdminDashboard.tsx`:
     - Quick KPI summary cards (Total Buildings, Faculty, Active Maintenance, Pending Reports, Events, Active Mess Outlets).
     - Tabbed operational consoles:
       1. **Issue & Ticket Triage**: Live queue of reported student issues with 1-click status update (`IN_PROGRESS`, `RESOLVED`) and staff resolution note.
       2. **Maintenance Notices Manager**: Publish new outage notices with alternative route suggestions.
       3. **Event & Fest Creator**: Schedule hackathons, workshops, and guest lectures with venue room association.
       4. **Notice Broadcaster**: Dispatch urgent emergency broadcasts or pinned circulars.
       5. **User Access & Roles**: View all users and upgrade role (`ROLE_STUDENT`, `ROLE_FACULTY`, `ROLE_STAFF`, `ROLE_ADMIN`).
3. **Routing & Navbar**:
   - Mount `/admin` in `App.tsx` wrapped in `ProtectedRoute`.
   - Show `Admin Console` button in `Navbar.tsx` user dropdown when user has `ROLE_ADMIN` or `ROLE_STAFF`.
