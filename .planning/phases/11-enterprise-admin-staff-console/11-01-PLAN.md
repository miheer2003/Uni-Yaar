# Plan 11-01: Backend Admin Metrics & Staff Management APIs

## Goal
Implement administrative analytics endpoints and back-office management APIs for campus operations, issue ticket triage, event publishing, announcements broadcasting, and role assignment under `/api/admin/**`.

## Key Changes
1. **DTOs**:
   - `AdminDashboardMetrics`: totalBuildings, totalRooms, totalFaculty, activeMaintenance, pendingReports, upcomingEvents, activeOutlets, totalAnnouncements, totalUsers.
   - `BuildingCreateRequest`, `RoomCreateRequest`, `NoticeCreateRequest`, `EventCreateRequest`, `AnnouncementCreateRequest`, `UserRoleUpdateRequest`.
2. **AdminService**:
   - Aggregate statistics across all entity repositories.
   - Spatial creation/update methods.
   - Ticket resolution & staff note updates.
   - User role upgrade/downgrade.
3. **AdminController**:
   - `GET /api/admin/stats`
   - `POST /api/admin/buildings`, `PUT /api/admin/buildings/{id}`
   - `POST /api/admin/rooms`
   - `POST /api/admin/maintenance`
   - `POST /api/admin/events`
   - `POST /api/admin/announcements`
   - `GET /api/admin/users`, `PATCH /api/admin/users/{id}/role`
4. **SecurityConfig**:
   - Ensure `/api/admin/**` has `hasAnyRole('ADMIN', 'STAFF')`.
