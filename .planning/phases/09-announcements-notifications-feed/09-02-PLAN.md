# Plan 09-02: Frontend Announcements & Live Notification Feed

## Goal
Build a campus notification hub with urgent emergency alert ticker banners, priority filters, audience tags, pinned announcements view, search, and detail dialogs.

## Key Changes
1. **Types & API Client**:
   - `frontend/src/types/announcement.ts`: `Announcement`, `AnnouncementPriority`, `AnnouncementCategory`, `AnnouncementAudience`.
   - `frontend/src/api/client.ts`: `announcementApi.getAll`, `announcementApi.getUrgent`, `announcementApi.getById`.
2. **Components & Page**:
   - `frontend/src/pages/Announcements.tsx`:
     - Red pulsing Urgent/Emergency Banner if active emergency alerts exist.
     - Priority & Category filter pills (All, Urgent, Exams, Placements, Transport, Hostels).
     - Audience selector tab (All Campus, Students Only, Hostellers).
     - Pinned notices section with gold badge.
     - Announcement card with priority ribbon, department tag, read time, and attachment/link buttons.
     - Modal viewer for full notice text.
3. **Routing & Navbar**:
   - Mount `/announcements` in `App.tsx` and add link to `Navbar.tsx`.
