# Plan 07-01: Backend Events & Hackathons Hub Architecture & Endpoints

## Goal
Implement backend entities, repositories, services, DTOs, and REST controller endpoints for campus events, hackathons, workshops, and guest lectures with venue room association, time filtering, category classification, and registration status.

## Key Changes
1. **Entity**:
   - `EventCategory`: Enum (`HACKATHON`, `WORKSHOP`, `CULTURAL`, `SPORTS`, `SEMINAR`, `TECH_TALK`, `CLUB_MEET`).
   - `EventStatus`: Enum (`UPCOMING`, `LIVE_NOW`, `COMPLETED`, `CANCELLED`).
   - `Event`: id, title, description, category, status, bannerUrl, organizer, registrationUrl, capacity, registeredCount, startsAt (LocalDateTime), endsAt (LocalDateTime), room (ManyToOne Room), locationName, contactEmail, isFeatured.
2. **DTOs**:
   - `EventResponse`: id, title, description, category, status, bannerUrl, organizer, registrationUrl, capacity, registeredCount, startsAt, endsAt, venueRoomId, venueRoomNumber, buildingName, buildingCode, latitude, longitude, contactEmail, isFeatured.
3. **Repository & Service**:
   - `EventRepository`: findByCategory, findByStatus, findUpcoming, findFeatured.
   - `EventService`: listEvents with optional category/status filter, getEventById, registerForEvent.
4. **Controller**:
   - `EventController` (`GET /api/events`, `GET /api/events/{id}`, `GET /api/events/featured`, `POST /api/events/{id}/register`).
5. **SecurityConfig**:
   - Allow public access to `GET /api/events/**`.
