# Plan 07-02: Frontend Event Discovery Hub, Details & Venue Navigation

## Goal
Build a vibrant, interactive Events & Hackathons Hub interface with category filtering, date filters (Today, This Week, Upcoming), live status indicators, modal event details with registration triggers, and one-click interactive map navigation to the exact campus venue.

## Key Changes
1. **Types & API Client**:
   - `frontend/src/types/event.ts`: `EventItem`, `EventCategory`, `EventStatus`.
   - `frontend/src/api/client.ts`: `eventApi.getAll`, `eventApi.getById`, `eventApi.getFeatured`, `eventApi.register`.
2. **Components & Pages**:
   - `frontend/src/pages/Events.tsx`:
     - Hero header with upcoming hackathon ticker.
     - Category filter pills with vibrant counters and icons.
     - Date segment filter (All, Today, This Weekend, Upcoming).
     - Event cards with rich banners, status chips ("🔴 LIVE NOW", "⚡ UPCOMING"), countdown / schedule time, venue info.
     - "Locate Venue on Map" button navigating with coordinates/building marker to `/map`.
     - Event Detail & RSVP modal with capacity bar, organizer contacts, and mock/real registration state.
3. **Routing**:
   - Update `App.tsx` to mount `/events` and update `Navbar.tsx` if needed.
