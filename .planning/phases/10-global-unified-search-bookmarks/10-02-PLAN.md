# Plan 10-02: Frontend Command Palette (Cmd+K) & Saved Bookmarks

## Goal
Implement a macOS Spotlight / Raycast-style Command Palette triggered anywhere in the app with `Cmd+K` or `Ctrl+K` and from the global search buttons, providing instant cross-campus discovery with grouped results, keyboard navigation, and bookmark management.

## Key Changes
1. **Types & API Client**:
   - `frontend/src/types/search.ts`: `SearchItemType`, `SearchResultItem`, `Bookmark`.
   - `frontend/src/api/client.ts`: `searchApi.query`, `bookmarkApi.getAll`, `bookmarkApi.create`, `bookmarkApi.delete`.
2. **Components**:
   - `frontend/src/components/search/CommandPalette.tsx`:
     - Global `keydown` hook (`metaKey || ctrlKey` + `k`, `Escape`).
     - Search input with clear button and loading spinner.
     - Grouped result sections: Buildings & Rooms, Faculty, Food & Dining, Events & Hackathons, Notices & Circulars, Maintenance.
     - Keyboard navigation (ArrowDown, ArrowUp, Enter).
     - Recent searches saved in local storage.
     - Bookmark toggle icon on each item.
3. **Integration**:
   - Mount `<CommandPalette />` in `App.tsx` so it is globally available.
   - Wire up Navbar search button to open the Command Palette.
   - Wire up Homepage hero search input to open the Command Palette with initial query.
